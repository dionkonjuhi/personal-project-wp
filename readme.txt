Personal Project WP theme

Features included:
- CSS and JS assets
- Custom Menus
- Post Loop in `index.php` and template parts
- Body classes via `body_class()`
- Page templates (template-fullwidth.php)
- `add_theme_support` for title, thumbnails, post-formats, etc.
- Post Formats support
- Sidebar and Widgets
- WP_Query sample (`ppwp_sample_query`)
- Template PHP files for search, 404, archive, single, page
- Tags display and `edit_post_link`
- Search form and results
- Pagination via `the_posts_pagination`
- Custom Post Type `project` with archive
