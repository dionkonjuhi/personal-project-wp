## ⚡ Quick Start (2 Minutes)

### Create Your First Legend
```
1. Go to WordPress Admin Dashboard
2. Click "Legends" in the sidebar
3. Click "Add New"
4. Enter:
   - Title: e.g., "Lionel Messi"
   - Featured Image: Upload a photo
   - Content: Write a biography
5. Scroll down and add Custom Fields:
   - position: "Forward"
   - years: "2004-2021"
   - nationality: "Argentina"
6. Click "Publish"
7. View your legend at: /legends/lionel-messi/
```

## 🛠️ How to Add Custom Fields

### Option 1: ACF Plugin (Recommended)
1. Install "Advanced Custom Fields Pro"
2. Create field groups
3. Fields appear in editor automatically

### Option 2: WordPress Native
1. Edit any post
2. Click "Screen Options" (top right)
3. Check "Custom Fields"
4. Add fields manually
